# CamperWifi v0.2.0

This release converts the working CamperWifi proof-of-concept into a public GitHub project structure. It adds an installable LuCI package source tree, automated repository validation, release ZIP generation, backup/restore tooling, diagrams, public contribution templates, and expanded documentation.

The package intentionally does not auto-provision network/firewall/wireless/mwan3 configuration. That remains a documented reference architecture until a safe configuration wizard is implemented.
